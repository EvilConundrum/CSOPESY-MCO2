## How to install and run the script?

### Installing the script
1. Run `git clone https://github.com/EvilConundrum/CSOPESY-MCO2.git`

### Windows
1. Open cmd or Powershell in `CSOPESY-MCO2\src`
2. You can either
   1. run the `run` batch file 
   2. manually compile and run with `g++ main.cpp -std=c++17 -pedantic-errors -o GreggyOS.exe` then `GreggyOS.exe`

### Linux

1. After cloning the repository, `cd CSOPESY-MCO2/src`
2. You can either 
   a. run `./run.sh` or
   b. manually compile and `g++ main.cpp -std=c++17 -pedantic-errors -o GreggyOS.exe` then `GreggyOS.exe`
